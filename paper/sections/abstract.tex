\begin{abstract}
% Background.
Text-to-SQL benchmarks compare models that answer natural-language questions over relational databases. Reusing their query structures can extend evaluation to new databases without constructing every task from scratch.
% Unresolved challenges.
However, executable SQL can misrepresent the intended task, and changes in workload composition can alter model comparisons. Structural coverage alone does not establish whether a migrated benchmark preserves source behavior or reflects model differences on the target database.
% Core method.
In this paper, we propose Schema2Bench (S2B), a framework for cross-domain benchmark migration. Benchmark Construction grounds source query patterns in target schemas and sampled values, then generates questions from SQL. Workload Selection adjusts composition under fixed quotas, bounds fidelity changes and identifies structural deficits in the candidate pool. Benchmark Evaluation separately measures source fidelity and agreement with model accuracy gaps on target references.
% Evaluation and results.
We compare five construction methods on eight BIRD databases with ten models, 2,000 tasks per method and 906 target references. In the main comparison under Verified execution scoring and declared weights, S2B reduces the template baseline's target gap from 0.225 to 0.169 and improves source fidelity over all four comparators. Fixed-SQL question rewriting lowers target gap but worsens source fidelity, showing why benchmark continuity and target model selection require separate assessment.
\end{abstract}
