\begin{abstract}
Evaluating Text-to-SQL systems on a new database requires a workload grounded in its schema and data. Existing benchmarks provide useful query structures, but adapting these structures can change the model comparisons obtained from the workload. We present Schema2Bench, a framework for constructing and evaluating migrated Text-to-SQL benchmarks. It distinguishes two evaluation objectives: preserving model behavior on the source benchmark and reproducing model-accuracy differences on target reference tasks. The framework combines schema- and value-grounded SQL construction, question realization and quota-constrained selection, with a tight bound on selection-induced changes and a certificate of missing structural coverage. We compare five constructions across eight BIRD databases and ten models, using 2,000 tasks per method and 906 target references. Deterministic refill reduces target-gap error from 0.225 to 0.169 relative to template construction and best preserves source behavior under the declared weights and execution-refined scoring. Ring-style construction gives lower target gap and mean model-selection regret. Controlled experiments locate most of the refill gain in construction; rewriting questions with SQL fixed further reduces gap to $[0.097,0.103]$ but worsens source fidelity. These findings show that construction choices should be assessed against the intended use of a benchmark, with separate checks for semantic validity and reference uncertainty.
\end{abstract}
